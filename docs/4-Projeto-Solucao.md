Diagrama macro que demonstra como os componentes do sistema se comunicam.

Front-end -> API (Back-end) -> Banco de Dados
 
### Diagrama de Arquitetura do Projeto 

Abaixo está o fluxo da aplicação, demonstrando a comunicação entre o Front-end, a API (Back-end) e o Banco de Dados.

```mermaid

    subgraph API_Django [API / Back-end Django]

    VIEW -- "Resposta (HTML/JSON)" --> UI
    MODEL -- "Consultas ORM" --> DB
    DB -- "Retorno de Dados" --> MODEL
```

#### Script SQL (DDL PostgreSQL)

```sql
-- Tabela: auth_user (fornecida pelo Django)
CREATE TABLE "auth_user" (
    "id" integer NOT NULL PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    "password" varchar(128) NOT NULL,
    "last_login" timestamp with time zone NULL,
    "is_superuser" boolean NOT NULL,
    "username" varchar(150) NOT NULL UNIQUE,
    "first_name" varchar(150) NOT NULL,
    "last_name" varchar(150) NOT NULL,
    "email" varchar(254) NOT NULL UNIQUE,
    "is_staff" boolean NOT NULL,
    "is_active" boolean NOT NULL,
    "date_joined" timestamp with time zone NOT NULL
);

-- Tabela: core_moodentry
CREATE TABLE "core_moodentry" (
    "id" bigint NOT NULL PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    "emotion" varchar(20) NOT NULL,
    "intensity_level" integer NOT NULL,
    "notes" text NULL,
    "created_at" timestamp with time zone NOT NULL,
    "updated_at" timestamp with time zone NOT NULL,
    "user_id" integer NOT NULL,
    CONSTRAINT "ck_intensity_level" 
        CHECK (intensity_level >= 1 AND intensity_level <= 10),
    CONSTRAINT "ck_emotion" 
        CHECK (emotion IN ('MUITO_FELIZ', 'FELIZ', 'NEUTRO', 'TRISTE', 
                           'MUITO_TRISTE', 'CANSADO', 'ANSIOSO', 'ALIVIADO')),
    CONSTRAINT "core_moodentry_user_id_fk" 
        FOREIGN KEY ("user_id") REFERENCES "auth_user" ("id") 
        ON DELETE CASCADE DEFERRABLE INITIALLY DEFERRED
);

-- Índices para performance
CREATE INDEX "idx_core_moodentry_user_id" ON "core_moodentry"("user_id");
CREATE INDEX "idx_core_moodentry_created_at" ON "core_moodentry"("created_at" DESC);
CREATE INDEX "idx_core_moodentry_user_created" ON "core_moodentry"("user_id", "created_at" DESC);
```
